# O Portal das Formas — Explore e Calcule

Coleção de páginas sobre formas geométricas e fórmulas de área, apresentada como material de estudo.

**Projeto desenvolvido para fins educacionais.**

**Demonstração informada no repositório:** [GitHub Pages](https://rafael-m-silva.github.io/o-portal-das-formas-explore-e-calcule/)

![Página inicial do Portal das Formas](./github/indexpaginainicial.JPG)

## Conteúdo

A página inicial apresenta formas como círculo, coroa circular, hexágono, tronco de pirâmide, retângulo, quadrado e trapézio. As páginas internas trazem explicações e campos para medidas.

## Estado atual

O repositório contém HTML e CSS, mas não contém os arquivos JavaScript referenciados pelas páginas de cálculo. Por isso os botões e resultados não devem ser apresentados como calculadoras funcionais neste estado. Alguns cartões da página inicial também apontam para uma página de outra forma. Essas pendências foram registradas sem alterar o código do exercício.

## Estrutura e execução

~~~text
index.html        catálogo de formas
*.html            páginas de cada forma
assets/css/       estilos
assets/images/    ícones das formas
github/           captura da página inicial
~~~

~~~bash
git clone https://github.com/Rafael-M-Silva/o-portal-das-formas-explore-e-calcule.git
cd o-portal-das-formas-explore-e-calcule
~~~

Abra <code>index.html</code> no navegador. Não há dependências a instalar. Para retomar a proposta de cálculo, implemente os scripts referenciados nas páginas e revise os destinos dos cartões.

## Aprendizados

O material pode apoiar aulas sobre geometria plana, fórmulas de área, formulários HTML e navegação entre páginas.
